# NETHA KEYBOARD ULTRA wallpapers

Upload your own JPG, JPEG, PNG, or WebP image files into this folder on the
`netha-keyboard-ultra` branch.

The keyboard app reads this folder from the GitHub Contents API and lists
supported image files in **Settings → GitHub wallpapers**. You do not need
to edit a catalog file. Keep images reasonably sized (ideally under 8 MB)
for faster downloads on mobile data.

After uploading, refresh the GitHub wallpapers list in the app.
