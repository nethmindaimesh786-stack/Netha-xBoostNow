# NETHA KEYBOARD ULTRA

A native Android Input Method Editor (IME) built with Kotlin.

## Build

```bash
./gradlew :keyboard:testDebugUnitTest :keyboard:assembleDebug
```

The APK is produced under `keyboard/build/outputs/apk/debug/`.

## Enable

Install the APK, open NETHA KEYBOARD ULTRA, choose **Enable NETHA KEYBOARD**,
then select it from Android's input-method picker.

## GitHub wallpapers

Upload JPG/JPEG/PNG/WebP images to the repository's `wallpapers/` directory
on the `netha-keyboard-ultra` branch. Open the app and refresh the GitHub
wallpaper list. The app lists supported image files and downloads the selected
wallpaper for local use.
