# NETHA DOWNLOADER

Android app for downloading direct video/audio file URLs that the user owns or has permission to save.

## Supported
- Direct HTTP/HTTPS media-file URLs (MP4, M4V, MOV, WebM, MKV, MP3, M4A, AAC, WAV, OGG, FLAC).
- Android share-sheet input for links.
- Android DownloadManager with notification and progress.
- Downloads are saved to `Downloads/NethaDownloader`.

## Platform links
YouTube, TikTok and Facebook page links are recognized and opened in the official platform. This app does not extract protected streams, bypass login/DRM/access restrictions, or download content contrary to platform terms or copyright. Use official download/export features for content you own where available.

## Build
GitHub Actions builds a debug APK on pushes to `main` and manual workflow dispatch. Download the APK from the workflow run's Artifacts section.
